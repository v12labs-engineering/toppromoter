# Security Policy

## Supported versions

This repository is a legacy public-beta snapshot. Only the latest commit on the
default branch may receive fixes; no release line is currently promised as
supported. Review the dependency audit and README security status before any
deployment.

## Reporting a vulnerability

Do not open a public issue containing exploit details, credentials, tokens,
personal data, or payment-provider payloads.

If GitHub's **Security > Report a vulnerability** option is enabled for this
repository, use it for a private report. Otherwise, contact the V12 Labs
maintainers privately through the contact method published on the
`v12labs-engineering` GitHub organization profile and request a secure channel.

Include the affected revision, impact, reproduction steps, and mitigation ideas.
Redact all secrets and personal data. No response-time SLA is promised while the
project remains in legacy status.
